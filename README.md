## Featured Projects

### [Teacher Notes Agent](https://github.com/abdullahsheikh01/teacher-notes-app)
Full-stack AI app for educators. Teachers generate, organize, summarize, and plan lessons through specialized agents with real-time streaming.
- **Stack:** Next.js · TypeScript · FastAPI · OpenAI Agents SDK · SQLite · SSE
- **Architecture:** Skill-based agent routing with 5 specialized agents (generate, organize, summarize, lesson-plan, chat triage)

### [Personal AI Employee](https://github.com/abdullahsheikh01/personal-ai-employee-digital-fte)
Autonomous AI agent that manages email, LinkedIn posting, and task processing — with human-in-the-loop approval at every external action.
- **Stack:** Python · Claude Code · Gmail MCP · Playwright · Obsidian
- **Architecture:** File-system watchers → intelligent orchestrator → approval workflow → MCP execution
- **Status:** Silver tier complete · Gold tier planned

### [Agentic Loop Engineering](https://github.com/abdullahsheikh01/agentic-ai-loop-engineering-projects)
Portfolio of autonomous agentic loops — self-fixing test suites, cron-driven daily briefs with memory, and unattended script watchers.
- **Stack:** Python · opencode · Shell · Cron
- **Pattern:** Shell scheduler + agent-in-the-loop with decision tokens (LOOP_CONTINUE / LOOP_DONE / LOOP_FAIL)

### [opencode Agentic Loop Skill](https://github.com/abdullahsheikh01/opencode-agentic-loop-skill)
Reusable skill for opencode: recurring autonomous tasks where opencode is the loop brain. Shell driver only schedules — every check, condition, and decision lives in the agent.
- **Stack:** Shell · opencode CLI

### [Docker Watchdog](https://github.com/abdullahsheikh01/opencode-docker-watchdog)
Interactive CLI that supervises Docker Desktop & Compose projects — picks a project, waits for Docker, optionally rebuilds, then monitors container health every 3 minutes.
- **Stack:** Python · Bash · Docker CLI · opencode · fzf
